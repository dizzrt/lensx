# macOS 原生验收证据

验收日期：2026-08-02

验收环境：macOS 原生 Tauri 开发窗口，主窗口标签为 `main`。窗口边界由 CoreGraphics 读取；截图由
macOS `screencapture` 按真实窗口 ID 保存。截图像素包含 Retina 缩放和原生窗口阴影，逻辑 viewport
尺寸以 CoreGraphics 边界为准。

## 原生交互结果

- `home` 初始边界为 `650×320`。从统一顶部槽下方空白间距拖动后，窗口从 `(431,172)` 移动到
  `(481,202)`，尺寸保持 `650×320`。
- 无移动主鼠标单击搜索输入后，输入可立即接收 ABC 英文键盘输入，窗口进入 `650×480` 的
  `search` 状态。
- 使用键盘全选英文查询后切换到系统 `Pinyin – Simplified` 输入源，真实输入法组合文本正常显示，
  未发起窗口拖动；Escape 正常取消组合并清空查询。
- 输入受控中文查询“设置”后，从搜索输入拖动将窗口从 `(481,202)` 移动到 `(521,227)`；随后从
  装饰头像拖动到 `(551,247)`。两次拖动均保持查询和 `650×480` 尺寸，且未执行 Action。
- 显式单击“打开设置”Action 后进入 `page`，边界为 `650×600`。从页面上下文非操作区域拖动到
  `(581,267)`，活动页面保持打开且尺寸不变。
- 单击页面关闭按钮及其图标区域没有移动窗口，返回 `home=650×320`；无需再次单击即可输入查询，
  证明输入焦点已恢复。键盘全选/清空后再次回到 `650×320`。
- 显式激活 Finder 后，launcher 按既有生命周期隐藏。发送系统级 `Ctrl+Shift+Space` 后，窗口恢复到
  `(581,267,650,320)`。
- 全程未发生最大化、缩放、意外页面关闭、意外 Action 执行或查询丢失。

## 固定 viewport 计算样式

计算样式来自同一次本地开发构建，并分别把浏览器 viewport 固定为原生逻辑尺寸。浏览器检查只用于
DOM/CSS 取证；窗口真实移动由上述 macOS 原生序列验证。

| 状态 | 关键证据 |
| --- | --- |
| `home=650×320` | `.launcher-surface` 为 `650×320`、`border-radius: 18px`、`overflow: hidden`；`html` 与 `body` 背景为透明；`.launcher-drag-region` 为 `650×68`，位于 `(0,0)`，`padding: 16px 16px 12px`，背景透明；顶部行位于 `(16,16)` 且高 `40px`；输入背景透明、圆角 `12px`；头像为 `36×36`、`border-radius: 50%`、`aria-hidden=true`、无 `role` 或 `tabindex`。 |
| `search=650×480` | surface 为 `650×480`；拖动容器仍为 `650×68` 且 padding 不变；输入仍为透明 `570×40`；内容从 `y=68` 开始且背景透明。 |
| `page=650×600` | surface 为 `650×600`；拖动容器仍为 `650×68`；页面上下文为透明 `570×40`、圆角 `12px`；关闭按钮为透明 `32×32`、圆角 `9px`，保留 `data-launcher-drag-exclude="true"` 和既有可访问名称；头像尺寸与位置不变。 |

计算样式未发现连续表面、圆角、透明背景、头像或顶部几何回退。
