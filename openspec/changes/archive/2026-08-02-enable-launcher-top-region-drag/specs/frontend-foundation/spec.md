## ADDED Requirements

### Requirement: 统一顶部拖动区域必须保留 App Shell 交互语义

App Shell MUST 将 `home`、`search` 和 `page` 状态共享的完整顶部表面作为一致的窗口拖动区域，同时 MUST 保留该区域内现有元素的产品语义、可访问性和键盘行为。搜索输入上的无移动主鼠标单击 MUST 继续聚焦输入并允许定位光标；主鼠标拖动 MUST 发起窗口移动且 MUST NOT 修改查询。键盘输入、输入法组合和键盘文本选择 MUST NOT 发起窗口拖动。

页面关闭按钮 MUST 继续作为可访问按钮工作，并 MUST 被排除在拖动手势之外。头像 MUST 继续是不可点击、不可聚焦、对辅助技术隐藏的装饰元素；允许从头像拖动窗口 MUST NOT 赋予头像按钮、链接、菜单或账户语义。该行为 MUST 在英语和简体中文以及浅色和深色主题下保持一致，且 MUST NOT 引入新的用户可见文案或持久视觉填充。

#### Scenario: 单击搜索输入但不移动指针

- **WHEN** 用户使用主鼠标按键单击搜索输入且未拖动指针
- **THEN** 搜索输入获得或保持焦点
- **THEN** 光标可以定位到用户单击的位置
- **THEN** 系统不修改查询且不执行 Action

#### Scenario: 从搜索输入拖动窗口

- **WHEN** 用户在搜索输入内按住主鼠标按键并移动指针
- **THEN** App Shell 请求原生窗口拖动
- **THEN** 搜索输入保持可编辑且当前查询不变
- **THEN** 该手势不要求同时执行鼠标文本范围选择

#### Scenario: 使用键盘编辑和选择查询

- **WHEN** 搜索输入具有焦点且用户输入文字、进行输入法组合或使用键盘选择文本
- **THEN** 输入继续遵循现有受控搜索行为
- **THEN** App Shell 不请求窗口拖动

#### Scenario: 在页面状态关闭活动页面

- **WHEN** 用户使用指针或键盘激活页面上下文关闭按钮
- **THEN** 关闭按钮不请求窗口拖动
- **THEN** App Shell 返回 `home` 状态并将焦点恢复到搜索输入

#### Scenario: 检查头像语义

- **WHEN** 用户或辅助技术检查支持拖窗的装饰头像
- **THEN** 头像没有按钮、链接、菜单触发器或键盘焦点语义
- **THEN** 从头像拖动窗口不会触发账户、导航或管理功能

#### Scenario: 切换本地化和主题

- **WHEN** App Shell 在英语或简体中文以及浅色或深色主题下呈现统一顶部区域
- **THEN** 相同的拖动和排除规则继续适用
- **THEN** 顶部区域保持现有连续表面外观且不出现仅用于指示拖动的持久填充或新文案

#### Scenario: 窗口拖动边界拒绝请求

- **WHEN** App Shell 请求窗口拖动但 Host 边界拒绝该请求
- **THEN** 搜索输入、查询、Action 选择、活动页面和焦点状态不被清除
- **THEN** App Shell 仍可通过现有键盘和指针交互继续使用
