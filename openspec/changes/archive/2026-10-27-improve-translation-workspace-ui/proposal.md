# Proposal

## Why

翻译插件已具有响应式原译文卡片和 400ms 自动翻译，但中文输入法的实际组合输入、语言栏层次、焦点样式与工作区高度仍需改善。用户要求更紧凑的双栏工作区、可用的语向互换，以及更少的常驻辅助文字；设置需要进入插件内独立设置视图，而不是追加在工作区下方。输入法提交必须保留中文正文，不能在组合期间提前翻译或被受控值回写覆盖。

## What Changes

- 保留宽视口左右双栏、窄视口原文在上且译文在下的同节点响应式布局，将 Manifest 初始尺寸调整为可缩放的 `800×480`，压缩内边距与正文最小高度，保留长内容和设置的滚动回退。
- 将顶部源语言、互换、目标语言组成居中的紧凑控件组；源语言使用主题主色实心胶囊，目标语言使用描边胶囊，设置入口留在右侧。源/目标文字标签视觉隐藏，完整可访问名称和键盘语义保留。
- 增加真实语言互换：只反转语言方向，不将译文交换或回填为原文。Auto 模式仅使用当前已确认结果的有效检测语言；不能形成受支持反向语对时禁用并解释原因。目标持久化确认后源与目标共同生效，明确失败保留原语对，结果不明沿用存储核对，保存期间禁止冲突语言操作。
- 修复中文组合输入路径，保留原生输入过程和最终提交字符；组合草稿不请求，最后一次提交后继续使用 400ms 自动翻译，并丢弃退休会话的迟到事件。
- 两张外层卡片采用一致中性表面，内部原文与译文分别使用中性与轻微主题色表面区分。移除文本区蓝色焦点大框和标题聚焦下划线，不增加替代装饰；保留原生光标、选择与控件语义。
- 移除工作区底部服务发送文字、译文空状态指引、原文计数和清空按钮。5000 Unicode code points 校验、超限错误、纯空白优先规则和原生删除/复制保持有效；服务发送告知放入设置说明。
- 互换按钮使用明确尺寸的可见 SVG，确保启用与禁用状态都能识别；关闭原文控件的拼写检查、自动更正、自动大写和自动完成请求，保留中文输入法候选与组合输入。
- 移除译文下方可见状态、RequestId 和检测语言；常规状态保留屏幕阅读器 live region，需操作的错误及重试放在语言栏附近。保留当前文档、Runtime、主题/语言及请求一致性，并同步测试、稳定规格和中英文文档。
- 设置入口切换到插件内独立设置视图，工作区隐藏且不可交互，但原文/译文节点与控制器保持挂载。设置提供“返回翻译”、保存和取消；进入时滚动到顶部并聚焦凭据，返回后恢复工作区滚动与设置入口焦点。失败保留设置草稿，未完成保存也可先返回继续编辑原文。

本次不新增手动或立即翻译、一键复制、朗读、文档/图片/语音翻译、翻译历史、新服务、新依赖或 Host 设置扩展。公开 API、存储结构、签名、HTTP 边界和请求时限保持不变；窗口变化仅使用现有 Manifest presentation 契约。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `official-translation-plugin`：紧凑的响应式卡片与初始尺寸、原生中文组合输入、带持久化确认的语言互换、精简常驻提示、内部表面与键盘焦点呈现、同文档独立设置视图与返回连续性；保留自动调度、限额、配置与服务安全边界。

## Impact

- 实施范围覆盖 `plugins/translation/src/TranslationPage.tsx`、`styles.less`、`catalog.ts`、`controller.ts`、必要设置协调、`manifest.json` 以及对应页面/控制器/样式测试。
- 互换复用已有目标语言确认后生效规则；不引入持久化源语言或新的配置字段。公开包、Provider、SDK 和 Rust Host 不新增产品能力。
- 原位同步 `docs/en/development/translation.md` 与 `docs/zh/development/translation.md`。当前 active artifacts 描述最终接受范围；只有实际实现与验证完成的行为才进入交付结论。
- 复用 `ci-plugins` 与完整前端/Rust 验证，不新增 Change 专用根脚本、GUI/浏览器验证或截图基线；安装、重载和发布不在本次授权内。

## 扩展范围（2026-10-23）

实施后的全量稳定规格严格校验发现 44 份历史规格共有 300 条正文超过 500 字符的警告。用户明确授权在本任务内清理全部历史警告。因此增加全仓稳定规格的语义保持整理：保留要求标识、既有场景和全部规范义务，将长正文细节移入对应可观察场景，缩短要求总述。此扩展不改变产品行为、公共契约、验证阈值或校验器配置；完成后重新验证全部规格并复核项目治理。
